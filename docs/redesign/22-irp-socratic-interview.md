# IRP 미확정 항목 문답식 입력

## 목적

세금 추가정보의 빈칸을 사용자가 의미를 모른 채 추측하여 채우지 않도록 한다. 기존 상세 입력은 고급 항목으로 보존하고, 기본 흐름은 계좌별 질문 하나만 보여준다.

## 질문 순서

1. 현재 잔액의 재원 구분
2. 혼합 재원이면 현재 퇴직금 원금과 과세제외 원금
3. 퇴직금 원금이 있으면 이연퇴직소득세율과 첫 수령연도
4. 개인납입금·운용수익이 있으면 중도해지 불가 종신계약 여부

앞 질문의 답에 따라 불필요한 뒷 질문은 만들지 않는다. 혼합 원금의 합계가 현재 잔액을 넘으면 후속 계산을 중단하고 수정 질문만 표시한다. 숫자 0과 `false`는 확인된 답이고, 빈 값은 미확정이다.

## 답을 모를 때

각 질문에는 확인할 금융회사 화면이나 서류, 포함·제외할 금액을 설명한다. 사용자는 질문을 건너뛸 수 있으며 이때 값을 생성하거나 저장하지 않는다. 세율은 직접 입력하거나 이연퇴직소득세(국세)를 이연퇴직소득으로 나눠 계산할 수 있다. 지방소득세는 세율 계산 입력에서 제외한다.

문답 답변은 편집 상태에 먼저 반영된다. 완료 화면의 `답변을 실제 데이터에 저장` 또는 페이지 상단 저장을 눌러야 IndexedDB와 다음 백업에 포함된다. 가져온 기존 데이터에 확인값이 있으면 해당 질문은 자동으로 생략한다.

## 기존 기능과의 관계

- 퇴직 시 계좌 합산과 미래 퇴직금 4.5억 연결은 기존 설정을 그대로 사용한다.
- 예정 퇴직금은 현재 잔액 재원 금액에 다시 넣지 않는다.
- 새 퇴직금의 세율은 목돈 분배 항목, 현재 계좌에 이미 들어 있는 퇴직금의 세율은 이 문답에서 관리한다.
- 계좌명으로 퇴직금·개인납입금을 추정하지 않는다.
- 직접 입력, 연도별 고급 가정, 기존 수동 인출 비율은 `전체 항목 직접 수정 · 고급`에서 유지한다.

## 검증

- `IrpFundingInterview.test.ts`: 질문 분기, 0/false 보존, 혼합 금액 검증, 불필요한 질문 생략.
- `check-irp-interview-ui.cjs`: 별도 합성 브라우저에서 문답을 순서대로 답하고, 저장 전에는 DB가 바뀌지 않으며 명시적 저장 후 0/false까지 보존되는지 PC·모바일에서 확인한다.
- `check-income-tax.cjs`: 문답 이후에도 기존 저장·분석·백업 흐름이 유지되는지 확인한다.
- 전체 단위 테스트, TypeScript 및 프로덕션 빌드, 데스크톱·모바일 화면 폭을 함께 검증한다.
