# 최근 3개월 누락 시세 복구

2026-09-15. 이 문서는 12번 문서의 ‘기존 날짜만 보정’ 설명을 대체합니다.

## 원인과 수정

개편 과정에서 자동 빈 날짜 생성 호출을 제거한 뒤, 새 시세 보정 함수가 기존 날짜만 처리하도록 만들었습니다. 그 결과 원래 사용하던 누락 일자 채우기가 사라졌습니다. 기존 동작을 보존하지 못한 기능 퇴행입니다.

설정의 **최근 3개월 시세 소급 업데이트** 버튼을 다음과 같이 복구했습니다.

- 시세 제공자가 반환한 최근 3개월 거래일에 기록이 없으면 이력을 추가합니다. 마지막 기록 이후의 빈 거래일도 포함합니다.
- 기존 날짜의 기록은 조회한 종가로 보정합니다.
- 빈 날짜의 수량은 직전 기록의 수량을 유지했다고 가정합니다. 중간에 수량 변경 기록이 있으면 그 이후에는 변경된 수량을 사용합니다.
- 추정 수량은 이력에서 표시하며, 수량 근거 날짜도 백업에 보존합니다. 새로 보간한 행을 다시 실제 거래 기록으로 취급하지 않습니다.
- 취득 전·오늘·종가 없는 날짜는 추가하지 않습니다. 과거 수량 근거가 없으면 오늘 수량을 대신 쓰지 않고 제외 건수를 표시합니다. 수량 0은 유효한 기록입니다.
- 기존 이력 없는 날을 원본 가격으로 무조건 채우던 전역 자동 마이그레이션은 복원하지 않습니다. 사용자가 버튼을 누르고 미리보기를 확인한 범위만 변경합니다.

## 사용법

1. 로컬 앱을 새로고침합니다. 재가져오기는 필요하지 않습니다.
2. 설정 → 과거 기록 보정 → 최근 3개월 시세 소급 업데이트.
3. 추가·보정·동일·수량 근거 없음·제외 건수를 확인하고 반영합니다.
4. 필요하면 ‘마지막 과거 시세 보정 되돌리기’로 이번 추가와 보정을 함께 되돌립니다.

현재 수량·현재 평가액·매입가·계획·저장 분석은 변경하지 않습니다. 반복 실행은 같은 날짜를 중복 생성하지 않으며, 변경 없음 결과가 직전 복구 사본을 지우지 않습니다. 미리보기 이후 원천 수량이나 이력이 바뀌면 재조회를 요구합니다. 반영 후 사용자가 수정한 행은 되돌리기로 덮거나 삭제하지 않습니다.

## 범위와 검증

현재 대상은 국내 원화 개별 종목입니다. 외화 자산은 과거 환율 없이 원화 평가액을 재구성하지 않도록 제외하고 화면에 건수를 표시합니다. 계좌 합계도 개별 시세로 보정하지 않습니다. 휴장일의 실제 종가는 존재하지 않으므로 거래일 기록만 추가합니다.

- 단위 테스트: 빈 거래일 추가, 기존 가격 보정, 수량 변경·0·미입력, 취득 전/오늘 제외, 재실행, 동시 수정 거절, 추가/보정 되돌리기, 추정 근거의 상세 조회 및 백업 왕복.
- 브라우저: 버튼 클릭 → 확인 → 추가 → 재실행 → 되돌리기.
- 합성 자산에서 누락 기록 3건 추가 확인.
- 실제 업로드 백업의 격리 사본에서 누락 기록 100건 추가 확인. 시세는 외부 요청을 차단한 **테스트 응답**이며 실제 투자 가격 검증은 아닙니다.
- 되돌린 뒤 원본 테이블·원본 파일의 일치 확인. 개인 데이터를 사용한 임시 브라우저 프로필 삭제 완료. 개인 데이터 스크린샷 없음.
- TypeScript 및 배포 빌드 통과. 앱 주요 묶음 440.83 KB (gzip 130.47 KB).

## 분석 방향에 대한 추가 피드백

사용자 의도는 새 계획 입력 체계를 만드는 것이 아니라 기존 자산·연금·생활비 입력을 연결해 결과를 자동으로 보는 것입니다. 기존 분석은 코드에 남아 있지만 현재는 ‘참고 계산기’로 뒤로 밀려 있습니다. 기존 분석을 기본으로 복귀시키고 신규 상세 계획은 고급 기능으로 분리하는 방향을 제안했습니다.

이 시세 복구 변경에는 분석 화면 전환이나 계산식 재통합을 포함하지 않았습니다. 후속으로 [14. 기존 입력 중심의 분석 복귀](14-existing-analysis-restored.md)를 적용했습니다. 그 문서의 연결 보완 범위와 남은 계산 한계를 확인하세요. 사용자 입력과 이미 저장한 새 계획/분석은 임의 삭제하지 않습니다.
