# 현재 자산 관리 우선 · 화면 간소화 적용

후속 수정: [13. 누락 시세 복구](13-history-backfill-restored.md). 아래 ‘빈 날짜를 만들지 않는다’는 당시 제한은 수정되어, 버튼 확인 후 빈 거래일도 추가합니다.

2026-09-15. 이 문서는 11번 적용 문서 이후의 화면 변경을 설명합니다.

## 사용자는 어디부터 시작하나요?

평소에는 홈의 **주식 계좌 확인·시세 갱신**을 누르세요. 계좌를 선택하고 종목·수량·평가액·배당을 확인하면 됩니다. 부동산·연금·예적금은 자산 메뉴에서 관리합니다. 이 작업에 은퇴계획 입력은 필요하지 않습니다.

은퇴계획을 보고 싶을 때만 **계획**을 여세요. 첫 화면의 안내 순서는 다음과 같습니다.

1. 은퇴 시점: 가구 구성원과 은퇴일 확인. 기존 은퇴 입력이 있으면 펼쳐서 검토용으로 복사.
2. 생활비·수입: 목록에서 필요한 항목 하나만 열어 수정. 추가한 항목은 즉시 열림.
3. 분석 전 확인: 자산 연결·인출 조건, 목돈·일정, 부채와 빠진 입력 범위를 확인한 뒤 저장 후 분석.

단계 이동은 자동 저장이나 확인 완료 처리가 아닙니다. 변경 사항은 저장 버튼으로 저장하며, 같은 탭의 초안 복구 기능도 유지합니다. 빈 날짜·금액·세율은 사용자 확인 없이 확정하지 않습니다.

## 무엇을 바꿨나요?

| 화면 | 변경 |
| --- | --- |
| 홈 | 현재 자산, 자산 관리 바로가기, 선택적인 은퇴계획의 세 영역. 주식 관리가 첫 행동. 이전 데이터 이전/재건축 점검 카드를 전면에서 제거. |
| 자산 전체 | 계좌별 주식 그룹 유지. 합산 기준 설명은 접되, 분류 미확인 시 합계가 잠정치라는 안내는 보임. |
| 계획 첫 화면 | 입력칸 0개. 무엇부터 할지 알려주는 시작 안내. 상세 설정은 아래에서 선택적으로 펼침. |
| 은퇴 시점 | 가구 입력 중심. 기준일·종료일·물가는 ‘계획 범위’에서 펼침. 기존 입력 복사도 선택적으로 펼침. |
| 생활비·수입 / 일정 / 부채 / 대안 | 이름·요약 목록으로 시작. 선택한 항목 하나만 수정. 선택 주소로 새로고침해도 해당 항목 유지. |
| 일정 입력 | 고정 날짜가 기본. 일정 연동·월/연 단위·날짜 이동은 상세 조건에서 펼침. 이미 상세 조건을 사용 중이면 보임. |
| 분석 전 확인 | 입력 범위 확인을 이 단계로 이동. 계산의 미확정 경고·근거·원장·이전 저장 결과 유지. |
| 설정 | 이전 입력 연결 내역과 과거 기록 보정을 접음. 백업/복원과 기존 기능은 유지. |
| 모바일 | 긴 계획 도구 모음이 화면을 가리지 않도록 고정 배치를 해제. |

상세 기능을 삭제한 것이 아니라 시작 화면과 노출 순서를 바꿨습니다. 주식 시세 갱신·종목 상세·배당·기록, 부동산·연금 관리, 기존 참고 계산기는 유지합니다. 재건축 관련 상세 일정은 필요한 사용자가 계획의 일정·목돈에서 관리합니다.

## 최근 3개월 시세 소급 업데이트

현재 평가액 갱신과 과거 이력 보정은 다른 기능입니다. 과거 보정은 **기존 날짜·수량 기록이 있는 국내 개별 종목**만 대상으로 합니다. 빈 날짜를 만들거나 오늘의 수량을 과거로 복사하지 않습니다. 외화 자산은 과거 환율 자료가 없어 제외합니다.

- 조회 중 완료 종목 수/전체 수 표시.
- 같은 종목이 여러 계좌에 있어도 한 번 조회하고 계좌별 기존 수량에 적용.
- 조회 실패, 이미 같은 시세, 보정 가능한 이력 없음 구분.
- 변경이 없으면 적용 확인창을 띄우지 않고, 직전 되돌리기 사본도 보존.
- 거래소 날짜는 Intl의 표시 문자열 대신 연·월·일 구성 요소로 조합.
- 변경이 있을 때만 미리보기 확인 후 반영. 현재 수량·현재 평가액·매입가를 수정하지 않음.

대표 공개 종목을 이용한 로컬 API의 1일/3개월 조회는 정상 응답했습니다. 이는 모든 보유 종목의 외부 조회 성공을 보장하지 않습니다. 사용자가 겪은 기존 실패의 단일 원인은 확정하지 못했으며, 진행/결과 안내와 무변경 처리 문제를 보완한 것입니다.

## 직접 사용 검증

- 기존 Chrome의 별도 임시 프로필에서 실행. 새 설치 없음.
- 1440px PC, 390px 모바일에서 보이는 버튼을 실제 마우스 이벤트로 클릭: 홈 → 주식, 계획 → 은퇴 시점 → 생활비·수입 → 분석 전 확인.
- 항목 펼침·접기, 선택 주소 재열기, 새 항목 자동 펼침, 입력 수정·저장·새로고침 확인.
- 합성 데이터로 현재 시세 갱신 성공/실패와 과거 보정 조회 실패 안내 확인. 과거 보정의 중복 조회·동일 시세·이력 없음·무변경 되돌리기 보존은 단위 테스트로 검증.
- 업로드한 실제 백업을 별도 프로필에서 복원해 PC/모바일 23개 경로, 4개 주식 계좌와 상세 기능 확인. 실제 데이터 외부 요청과 스크린샷은 차단.
- 가져온 원본 테이블과 원본 파일이 변경되지 않았음을 비교. 테스트 중 만든 계획은 임시 프로필 안에만 저장하고 종료 시 프로필 삭제 확인.
- 자동 테스트 158개 통과. 화면 검증 중 브라우저 예외와 가로 넘침 없음.
- TypeScript 검사와 배포용 빌드 통과. 앱 주요 묶음 438.62 KB (gzip 129.70 KB). 빌드 성공을 모든 외부 시세 제공자나 세법 조건에 대한 검증으로 해석하지 않습니다.

화면 예시는 [실제 앱 화면 모음](actual-screens.html)에 있습니다. 모두 가상 데이터이며 개인 금융정보가 아닙니다.

## 유지한 경계

계산 엔진 버전과 저장 스키마는 변경하지 않았습니다. 과거 분석 결과·개인 입력을 자동 덮어쓰지 않습니다. 단순한 UI가 세금 자동 산출 또는 확인되지 않은 분석의 정확성을 보증한다는 뜻은 아닙니다. 인출·세금·재건축 날짜 연결 등 실제 분석에 필요한 조건은 여전히 검토가 필요하며, 이를 일상적인 자산 관리의 선행 조건으로 요구하지 않습니다.

이번 작업은 로컬 소스와 화면에 적용했습니다. Git 커밋·푸시·외부 배포는 수행하지 않았습니다.
