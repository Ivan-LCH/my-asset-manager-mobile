# 최신 자산 명의·일반주식·생활비 연결 보완

적용일: 2026-09-17. 기존 입력 및 분석 화면을 보완하며 별도 계획 생성이나 실제 사용자 데이터의 일괄 변경은 하지 않는다.

## 1. 연금 명의

- 자산에 연결된 연금은 현재 자산의 단독 명의를 우선한다. 과거 시뮬레이션 명의가 최신 자산 명의를 덮어쓰지 않는다.
- 수동 연금 원천, 수동 세금 분류, 등록 수령액·수령 기간은 보존한다.
- 공동지분·미확정 명의는 자동 분할하지 않는다. 기존 분석 명의(없으면 남편)를 임시 사용하고 확인 문구를 표시한다.
- 조회만으로 DB를 갱신하지 않는다. 사용자가 연금 시뮬레이션을 저장하면 최신 명의를 반영한 설정을 저장한다.
- 분석 요약·연금 상세·현금흐름·명의별 세금·건보 입력은 같은 지급 원장을 사용한다.

## 2. 일반주식 연결

개인투자시뮬 → 일반주식계좌 → 투자금 입력 기준에서 선택한다.

- 기존 데이터는 **수동 투자금·배당률** 모드를 유지한다. 기존 수동 금액이 현재 계좌를 포함한 것인지 자동 판단할 수 없으므로 임의 전환하지 않는다.
- **현재 일반주식 잔액·배당 연결** 모드에서는 현재 평가액·계좌 명의·배당 예상액을 재사용한다. 시세·배당 설정 갱신 후 다시 계산되며, 계좌 목록에서 근거를 확인할 수 있다.
- 계좌 명의 설정을 우선하고 없으면 자산 지분을 사용한다. 잘못되거나 없는 지분은 50:50 임시 가정과 확인 안내를 표시한다.
- 연금 지급에 사용하는 계좌 전체, 연금성 주식 계좌, 처분 자산을 제외한다. 계좌 합계 행과 종목 행을 중복 더하지 않는다.
- 수동 추가 금액을 실제 계좌와 더하지 않는다. 수동값은 저장 상태로 보존하므로 수동 모드로 돌아갈 수 있다.
- 현재 연결 배당은 자산의 DPS/배당률 설정으로 산출한 **예상액**이며, 실현 입금액이나 외부 시세 공급자의 정확성을 보장하지 않는다. 0원은 무배당/미입력 확인을 안내한다.
- 미래 목돈은 해당 수령 연도부터 반영하며 별도 입력 배당률을 사용한다. 현재 연결 배당과 잔액에는 기존 주가상승률을 매년 적용하는 계획 가정이다. 원금 생활비 인출이나 배당 재투자 정책을 추가한 것은 아니다.
- 일반주식의 기준년도 잔액·연배당 설명도 연도별 원장과 같은 값을 사용한다.

## 3. 생활비 물가 설정

생활비·목돈 입력 → 생활비/여행/의료비에서 기준연도·연 증가율을 설정한다.

- 미설정은 기존 고정 금액 유지, 0%는 명시적 고정 가정이다. 특정 권장률을 자동 입력하지 않는다.
- 기준연도 이후 생활비·여행비·의료비에 `(1 + 증가율/100)^(선택연도 - 기준연도)`를 적용한다. 기준연도 이전은 입력 금액을 유지한다.
- 여행 횟수 변경은 기존 연도 구간대로 적용한다. 세금·건보·목돈·일회성 지출은 물가율을 중복 적용하지 않는다.
- 원본 입력 금액은 보존하고 요약·상세 항목·연도별 현금흐름이 동일한 환산값을 사용한다.

## 남겨 둔 확인 사항

- 여러 IRP 중 4.5억 입금 대상, 실제 건강보험 세대, 재건축 전환일·공사 중 세금, 실제 소유 지분은 사용자가 확인해야 한다. 프로그램이 임의로 정하지 않는다.
- 공사 중 토지 건보 과표, 실제 과세표준·세금 특례, 가입자 자격 전환, 대출 상환·임대보증금 반환의 전체 생애주기 자동화는 이번 범위에서 완성한 기능이 아니다.
- 수익률 시나리오 비교나 장기 시뮬레이션 전체의 세무 정확성을 보증하는 작업이 아니다. 기존 상승률·배당률을 그대로 보존한다.

## 검증 경로

- `inputLinkage.test.ts`: 최신 명의 양방향 변경·미확정 경고·원본 보존, 계좌별 명의, IRP/처분 제외, 합계행 중복 방지, 실제 잔액·배당 갱신, 미래 목돈 시점, 수동값 보존, 물가 적용 범위.
- `check-input-linkage.cjs`: 개인 명의 결과, 수동값 보존 및 연결 선택·저장, 물가 설정 저장·상세 일치, 백업 왕복, PC/모바일, 열람 원본 불변, 평가액 갱신 후 분석 갱신. 모두 격리된 가상 데이터만 사용한다.
- 전체 단위 테스트 218개 / 17개 파일 통과. 실제 백업을 메모리에서만 재현해 명의 충돌 2건 해소, 가구 연금 수입 합계 불변, 아내 국민연금 귀속, 원본 파일·입력 불변을 확인했다. 실제 개인별 금융정보는 코드·문서·스크린샷에 넣지 않는다.
- 최종 타입 검사·배포 빌드 통과. 기존 분석/IRP 브라우저 회귀 검사와 새 연결 기능 PC(1440px)·모바일(390px) 검사를 통과했다. 마지막 모바일 배분 버튼 정리 후 `node tools/check-local-app.cjs --linkage`로 재검증했으며 월 소득·물가 지출·백업 왕복·원본 보존·현재 평가액 갱신·화면 너비 검사를 통과했다. 외부 실거래·시세 공급자·Google 인증 검증을 뜻하지 않는다.
