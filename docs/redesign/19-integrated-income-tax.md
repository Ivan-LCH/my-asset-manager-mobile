# 연금·금융 통합세금 보완

2026-09-17. [18번 금융소득세 보완](18-financial-income-tax.md)의 후속이며,
기본 분석의 **연금 연동 모드와 개인투자시뮬**은 이 문서의 통합 계산을 우선한다.
법인 모드·별도 고급 월별 계획의 기존 세금 정책은 이번 변경 대상이 아니다.

## 사용자 확인 순서

1. `분석 → 세금 상세 → 연금·금융 종합세금 내역`을 펼친다.
2. 본인·아내별 `확인이 필요한 정보`를 확인한다.
3. `세금 추가정보 확인·수정`을 누르면 기존 개인투자 화면의 추가정보가 열린다.
4. 확인된 항목만 입력하고 기존 상단 **저장** 버튼을 누른다.

수령액·연금 시작일·명의·배당액을 새로 입력하지 않는다. 필요한 것은 세무 구분이다.
모르면 빈칸으로 두고, ‘해당 없음’이 확인된 때만 0을 입력한다.

| 항목 | 연결/계산 방식 | 추가 확인 정보 |
|---|---|---|
| 국민연금 | 등록 지급액 중 과세대상액을 연금소득공제 후 종합합산 | 연금기관 증명서의 과세대상 비율. 미확인은 전액 과세 가정 표시 |
| 개인납입·운용수익 연금 | 개인별 사적연금 합계와 나이에 따른 분리과세 또는 종합합산 선택 | 과세 선택, 종신계약 여부, 설정의 생년월 |
| 퇴직금 재원 IRP | 다른 종합소득과 분리, 실제 수령연차별 감면계수 적용 | 인출 재원 비중, 이연퇴직소득세율, 실제 첫 수령연도 |
| 적격 배당 | 일반 금융소득 중 확인된 적격 배당의 가산·세액공제 및 비교과세 | 배당공제 대상 비율. ETF·해외 배당을 자동 적격으로 보지 않음 |
| 인적·기타 소득공제 | 개인별 한 번 적용. 미입력은 본인 150만원만 | 가족 공제 요건·귀속을 확인한 합계. 연금소득공제는 별도 자동 계산 |
| 외국납부세액 | 특정 연도의 국외소득·외국납부액·확인된 공제 가능액 반영 | 국세/지방세 공제액, 국내 전체 기납부액 |
| 표준·자녀 등 세액공제 | 소득금액에서 빼지 않고 해당 연도 산출세액에서 차감 | 요건 검토가 끝난 국세·지방세 금액 |

IRP의 퇴직금 재원과 개인납입 원금·운용수익은 같은 계좌에 있어도 과세 방법이 다르다.
재원 비중은 **계좌 잔액의 비중이 아닌 해당 인출액의 비중**이다. 매년 적용할 가정을
설정하고 재원이 달라지는 연도는 별도로 덮어쓸 수 있다. 미래 목돈을 합산한 IRP도
증가한 실제 예상 지급액에 이 구분을 적용한다. 재원 순서를 임의로 만들어내지는 않는다.

## 계산 계약

공통 엔진: `frontend/src/lib/incomeTax.ts`, 계산 식별자 `KR-2026-income-v2`.
연도 요약·현금흐름·개인투자·상세 화면이 같은 함수를 사용한다.

- 국민연금 과세대상액과 종합합산 선택 사적연금에 법정 연금소득공제를 한 번 적용한다.
  공제는 지급액 구간별 계산, 최대 900만원이다. 기존 고정 1,200만원 모형은 사용하지 않는다.
- 위 연금소득금액·금융소득·기타 종합소득금액을 합산한 후 개인별 소득공제를 적용한다.
  기존 배우자·부양가족·‘표준공제 100만원’의 부부 절반 배분은 중단한다.
  기존 설정 자체는 삭제하지 않는다.
- 적격 배당 가산대상은 확인된 적격 금액과 금융소득 2천만원 초과분 중 작은 금액이다.
  10% 가산 후, 가산액과 비교산출세액 초과액 중 작은 금액을 배당세액공제로 적용한다.
  가산액은 세무 계산상의 금액으로 월 수입·계좌 원금에 가산하지 않는다.
- 사적연금 분리과세는 국세 기준 70세 미만 5%, 70~79세 4%, 80세 이상 3%이다.
  확인된 중도해지 불가 종신계약은 2026년 기준 3%다.
  분리과세 선택 시 대상 사적연금이 연 1,500만원을 초과하면 15% 국세를 적용한다.
  종합합산을 선택하면 별도 사적연금세를 다시 더하지 않는다.
- 이연퇴직소득 재원 연금에는 입력한 국세 효과세율에 실제 수령연차 기준
  1~10년 70%, 11~20년 60%, 21년 이상 50% 계수를 적용한다.
  명시적 0%와 미입력을 구별한다. 미입력 IRP 세금은 **미확정 소계**로 알린다.
- 국내 산출세액의 지방세는 별도로 계산한다. 공제·기납부는 국세/지방세 합산 계약을
  화면에 명시하며 원 단위 반올림으로 계산한다. 법정 단수처리와 소액 차이가 날 수 있다.

`국내 총세금 + 외국납부액 = 총세금 부담`이며,
`국내 기납부액 + 외국납부액 + 국내 정산액 = 총세금 부담`이 항상 성립한다.
기납부액 수정은 추가 납부/환급만 변경하고 총세금 자체를 바꾸지 않는다.
현금흐름에서는 총 부담을 한 번만 차감한다. 환급을 수입으로 한 번 더 더하지 않는다.
해당 연도 기준 비용 추정이며 실제 지급월·다음 해 신고월의 현금 이동을 재현하지 않는다.

`annualVehicle` 호환 필드의 `pensionTax`는 분리 연금세,
`financialTax`는 그 외 종합·금융세 및 해외 부담을 의미한다. 화면도 이에 맞게 표시한다.
구 `pensionTaxCombined`/`annualFinancialTax`는 과거 계산 호환용이며 새 통합 화면에서는 호출하지 않는다.

## 데이터가 부족할 때

재원·세율 미확정 IRP의 세금을 0원 확정으로 표시하지 않는다. 세금 제목에 ‘미확정’을
붙이고, 세금 제외 대상 인출액·사유를 표시한다. 이때 추가 납부·환급액도 숫자로 확정 표시하지 않는다.
누적 금액도 ‘미확정 연금세 제외’임을 알린다.
과세대상 비율·배당공제 비율 등은 적용한 가정과 확인 필요 사항을 표시한다.

외국납부세액은 **한도 검토가 끝난 금액을 입력하여 반영**하는 방식이다.
국가별 자동 공제한도·조세조약·이월공제·국내 상장 해외투자 펀드의 간접공제 계산기는 구현하지 않았다.
입력 공제액은 국내 산출세액 등 범위로 제한하지만, 이 제한이 법정 국가별 한도 검증을 대신하지 않는다.
원화 환산은 증명자료 기준으로 입력하고, 해외 수입을 별도 새 수입으로 더하지 않는다.
입력값은 특정 개인·특정 연도에만 적용되며 미래 연도 또는 배우자에게 복사하지 않는다.

그 밖에 연금수령한도 초과·연금외수령·퇴직연금 수령 중단 연차·보험차익 과세·특별 원천징수율,
가족 공제 자격 자동 판단은 별도 확인이 필요하다. 연령은 연말 나이 기준의 연간 추정이다.
미래 세법 개정은 예측하지 않고
2026년 확인한 규칙을 유지하는 시나리오다. 신고서 제출용 완전한 세무 계산기는 아니다.

## 저장·호환

선택 필드 `PensionSimPlan.incomeTaxSettings`에 개인별 가정, 원천별 기본 재원,
연도별 원천 재원 덮어쓰기, 연도별 기납부·공제액을 저장한다. DB 테이블·설치는 추가하지 않는다.
기존 백업은 그대로 읽고 새 필드는 백업 내보내기/가져오기로 왕복 보존한다.
조회만으로 설정을 저장하거나 확인 완료 처리하지 않는다.
수동 과세/비과세 구분의 `taxTypeManual`이 재연결 후 사라지던 문제도 함께 수정했다.
