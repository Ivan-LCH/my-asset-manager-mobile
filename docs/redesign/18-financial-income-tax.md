# 금융소득세 누락 보완 — 2026-09-17

> 후속 [19. 연금·금융 통합세금](19-integrated-income-tax.md)이 적용되었습니다. 아래는 금융소득 단독 산출 단계의 기록이며, 최신 기본 분석의 연금 연동 결과는 19번을 따릅니다.

## 확인 위치

`분석 → 세금 상세 → 금융소득세 내역`에서 남편·아내 각각 연간 금융소득,
일반 금융소득 2천만원 초과 여부, 원천징수 예상액, 추가 납부 예상액, 총세금 부담을 확인한다.
동일한 내역을 `개인투자시뮬 → 지출 상세`에서도 제공한다. 새 입력 화면은 만들지 않는다.

## 변경 내용

| AS-IS | TO-BE |
|---|---|
| 첫 2천만원의 원천징수만 총세금에 포함하고 초과분 원천징수는 누락 | 일반 금융소득 전체 원천징수 + 추가 세금 = 총세금 |
| 비교과세 하한 없이 초과분 누진세에서 원천징수를 빼고 0원 처리 | 일반 산출세액과 비교 산출세액 중 큰 금액 적용 |
| 모든 금융소득에 임의 배당가산·배당세액공제 적용 | 적격 배당 구분이 없어 가산·공제하지 않음; 한계 명시 |
| 일부 누진공제액 오류, 종합과세 부분 지방세 불명확 | 제55조 기본세율 경계 정정, 국세 산출 후 지방세 10% 가산 |
| 총액만 표시해 0원이 면세처럼 보임 | 원천징수와 추가 납부를 구분, 0원 의미 안내 |
| 세금 표시가 전액 별도 연납인 것처럼 보임 | 연간 추정 부담으로 표기, 월 여유/부족은 세전임을 표시 |

## 계산 계약

단위는 개인별 연간 원. 국내 일반 이자·배당(국세 원천징수 14%)을 가정한다.
선택분리과세로 설정한 금액은 일반 금융소득에서 제외하고 기존 별도 모형을 유지한다.

- F: 일반 금융소득, O: 입력 기타소득, D: 기존 설정에서 계산한 공제 가정.
- F > 2천만원인 경우 A = 2천만원 × 14% + 기본세율(max(0, F - 2천만원 + O - D)).
- B = F × 14% + 기본세율(max(0, O - D)).
- 일반 부담 = round(max(A, B) × 1.1). F가 2천만원 이하면 B × 1.1.
- 전체 원천징수 예상 = 일반 금융소득 × 15.4% + 선택분리 대상 소득 × 15.4%, 각각 원 단위 반올림.
- 총세금 = 일반 부담 + 선택분리과세 모형의 세금.
- 추가 납부 예상 = 총세금 - 전체 원천징수 예상.

`annualFinancialTax`를 연도별 세금·개인투자·상세 화면이 공유한다.
기존 `totalFinancialTax` 반환 계약은 **입력 기타소득 세금 포함**이므로 기타소득이 있으면
화면도 ‘금융·기타소득세’로 표시한다. 기타소득의 기납부세액을 알 수 없어 추가 납부액에서 차감하지 않는다.

세전 배당은 기존 월 수입에 유지한다. 총세금은 기존 `incomeTaxAnnual → taxAnnual` 경로로
누적 현금흐름에서 한 번만 차감한다. 원천징수·추가 납부는 이 총액의 분해이며 별도 지출로 더하지 않는다.
이는 소득 발생 연도 기준 추정이며 실제 배당 지급일이나 다음 해 신고 납부일의 현금흐름을 재현하지 않는다.

합성 회귀 예: 일반 금융소득 2,100만원, 기타소득 없음, 공제 가정 150만원이면
원천징수 323.4만원, 추가 납부 0원, 총 부담 323.4만원이다.
1억원이면 동일 조건에서 원천징수 1,540만원, 추가 납부 206.8만원, 총 부담 1,746.8만원이다.

## 지원 경계

확정 신고세액 계산기가 아니다. 배당가산·배당세액공제, 외국납부세액, 해외 배당,
특별 원천징수율, 공적·사적 연금과의 법정 종합합산, 정확한 소득공제·세액공제는 미구현이다.
적격 배당 세액공제를 생략한 경우 부담을 과대 추정할 수도 있다.
기존 연금세 및 인적공제 가정은 변경하지 않았으며 전체 소득세를 세법상 정확한 합산액으로 해석하면 안 된다.
선택분리과세는 저장된 비율·기존 세율을 유지한 시나리오로, 적용 자격과 미래 연장을 검증하지 않는다.
2031년 등 미래 연도에도 현재 모형을 적용한다. 실제 신고 전 별도 세무 확인이 필요하다.

입력 자료·저장된 설정은 자동 수정하지 않는다. 백업 스키마 변경과 설치는 없다.
